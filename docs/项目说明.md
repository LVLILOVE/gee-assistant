# 卫星遥感影像智能分析助手 · 项目说明

## 1. 项目概述

卫星遥感影像智能分析助手是一款面向**非遥感专业用户**的对话式遥感分析 Web 应用。用户无需编写任何代码，只需用一句中文描述分析需求，系统即可自动完成「意图解析 → 代码生成 → 沙箱执行 → 自动调试 → 地图与图表可视化」的完整链路。

项目本质是**智能体（Agent）链路工程**：以自然语言为入口，以大模型为代码生成与自修复引擎，以可插拔执行后端（真实 GEE / 离线样例）为计算底座，将专业遥感分析能力"平民化"。

## 2. 目标用户

- 生态与环保监测工程师、农业分析师、科研人员（生态学、地理学等）；
- 有明确遥感分析需求、但不具备 GEE 编程能力的**零代码 / 低代码用户**；
- 通过浏览器以中文自然语言完成分析，无需安装任何专业软件。

## 3. 核心功能

| 功能模块 | 说明 | 状态 |
|---|---|---|
| 对话式需求解析 | 自然语言理解 + 多轮澄清，缺参自动追问 | ✅ |
| 代码生成 | 大模型（DeepSeek）生成 GEE Python 代码 | ✅ |
| 沙箱执行 | 受控后端执行，解析出影像图层与统计结果 | ✅（离线兜底） |
| 自动调试 | 错误分类 + 修复重试，达上限给人工建议 | ✅ |
| 可视化与报告 | 地图渲染 + 统计图表 + 报告导出 | ✅ |
| 任务与用户管理 | 历史任务 + 常用区域配置 + sqlite 持久化 | ✅ |
| 真实 GEE 执行 | 调用 Google Earth Engine 云端计算 | 🟡 待服务账号凭据 |

四类分析模板：植被指数 NDVI、水体提取、地表分类、时序变化检测。

## 7. 关键技术点

### 7.1 可插拔执行后端
执行层定义统一 I/O 契约 `ExecutionOutcome`（图层 + 图表 + 错误分类），前端与编排层不感知后端差异。`EXECUTION_BACKEND=offline` 时走内置样例，`gee` 时走真实 Earth Engine——保证 GEE 账号/网络未就绪也能跑通全链路并对外演示。

### 7.2 LangGraph 编排
「生成 → 执行 → 调试」状态机：生成代码 → 执行 → 失败则分类错误并调用大模型修复 → 重试，达上限后给出人工介入建议；鉴权类错误不重试。

### 7.3 多轮澄清
意图解析返回结构化参数 + 缺失字段 + 澄清问题；`partial` 参数携带已确认字段，续问时只补齐缺失项，实现自然的多轮对话。

### 7.4 降级兜底
未配置 DeepSeek key 时，代码生成降级为内置模板、意图解析降级为关键词规则——系统始终可运行。
