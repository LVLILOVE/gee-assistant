## 一、先量化：历史栅格图层**全部**失效

把 50 条任务逐条拉详情，取出带 `tile_url` 的栅格图层，各请求一次 `/api/tile/`：

| 项 | 值 |
|---|---|
| 任务总数 | 50 |
| 有栅格图层的任务 | **46** |
| 其中瓦片返回 200 的 | **0** |
| 全部返回 | `400 {"detail":"瓦片请求被拒绝：GEE 返回 401"}` |
| 最新一条栅格任务的生成时间 | 2026-09-24 11:08:11（距今约 **97 小时**） |

**为什么"全军覆没"是合理的、不是又一次故障**：这批任务跨 09-15 ~ 09-24，
若连最新的都失效，那只能是"令牌寿命比 4 天还短"。这与 GEE `getMapId()` 的行为一致 ——
它返回的瓦片地址里嵌的是**短期访问令牌**，不是永久链接。所以：

> **本产品的栅格图层只有短期可看性。** 产物算出来、报告存下来，
> 但地图上的色块过期即失效，此后打开历史任务只会看到灰底图。

这是产品级事实，不是 bug（GEE 侧设计如此），但它决定了"打开历史任务"的默认体验。
建议见第七节。

## 三、顺手抓到并修掉：告警正文里的 **Markdown 残留**

浏览器把告警正文抓回来时，看到的是：

```
… 令牌只能由 GEE 在**重新计算时**签发，没法凭空续期 —— …
```

`MapPanel.jsx` 里这段是 **JSX 文本节点**（不是注释），而 JSX 不解析 Markdown ——
**用户屏幕上原样显示四个星号**。

**读代码为什么没发现**：本仓库注释里到处是 `**`（文档式注释是这里的风格），
`grep -n '\*\*'` 出的几十条里只有 1 条在正文，噪音淹没了信号。
只有把渲染后的文本取回来才看得见。

**修法**：正文里的强调改用 `<strong>重新计算时</strong>`。

| 阶段 | 证据 |
|---|---|
| 修复前 · 已上线的 bundle | `MapPanel-O8Ih6pRQ.js` 内含字符串 `**重新计算时**` |
| 修复前 · 浏览器抓到的 DOM 文本 | `…在**重新计算时**签发…` |
| 修复后 · 源码 | `frontend/src/MapPanel.jsx:299` 改为 `<strong>` |
| 修复后 · 新 bundle | `jsx("strong",{children:"重新计算时"})`；不再含 `**重新计算时**` |
| 修复后 · 线上复核（HTTP 取内容） | 首页引用 `index-QoXW_KzN.js`；`MapPanel-BXN2iNNL.js` 200，`has_literal_md=false`、`has_strong=true`；旧 chunk 返 404 |
| 修复后 · 浏览器复核 | 告警正文变为 `令牌只能由 GEE 在重新计算时签发…`（无星号） |

**新增回归守卫**：`backend/tools/test_jsx_markdown_leak.py`（6/6 通过），已接入
`tools/regress_all.sh` 默认清单。
判据是"**先剥注释、再找 `**`**"，且**只查 `**`** ——
第一版连反引号一起查，扫出 16 处**全部是 JS 模板串**（误报），
而 `**` 在 JS 里只可能是幂运算，凑不出"四个星号夹一段文字"，判据是精确的。

**守卫不是空转（双向证明）**：
① 对**浏览器抓到的正文** → 命中 1 处；
② 对**已上线 bundle** → 命中 1 处；
③ 对**修复后的源码** → 0 命中。

## 六、本次踩到的两个"我自己量错"（记下来以免复演）

1. **字符数 ≠ 字节数**。`len(read_text())` 得到 28658，`stat().st_size` 是 31566，
   中文 bundle 差 ~10%。据此误判成"重建后产物小了 2908B、疑似被并发写者覆盖"，
   白排查一轮。（已写进 `headless-browser-verify-cn` 技能。）
2. **拿 `git HEAD` 当"修复前基线"只在缺陷已提交时成立**。第一版守卫自检用 HEAD 当 before，
   命中 0，一度判成"判据坏了" —— 其实那段告警整体属于**未提交的在途改动**。
   改用"浏览器抓到的 DOM 文本 + 已上线 bundle"两个物证后，双向验证成立。

## 七、遗留风险与建议

1. **P1 · 图层寿命是产品级问题（未修）**。当前唯一的补救是"按原参数重跑一次"，
   意味着用户每次打开几天前的任务都要重烧一遍 GEE 算力才能看到图。
   两个可选方向：
   - **任务完成后把瓦片落盘缓存**（按任务 + z/x/y 存本地 PNG，经 `/api/tile/` 命中缓存）
     —— 历史任务永久可看，且省 GEE 配额；
   - 或**详情页点开时后台异步重算并替换 `tile_url`** —— 改动小，但仍依赖 GEE 可用。
2. **并发写者**：本次全程确认有另一个会话在同一仓库编辑（`MapPanel.jsx`/`App.jsx`/
   `main.py`/多个 `tools/*` 未提交；`dist` 于 12:16 被重建）。我只改了自己该改点的
   最小范围，**未触碰其未提交文件**；但建议后续只保留一个会话写这个仓库。
3. 未提交清单（in-flight）：`main.py`、`App.jsx`、`MapPanel.jsx`、`style.css`、
